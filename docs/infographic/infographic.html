Two scanners, two different sets of report formats

Semgrep reads the source code (SAST); OWASP ZAP attacks the running application (DAST). Both are free. Each scans once and writes all of its own formats from that scan: the formats are not shared between the two tools.

Security tooling briefing · Semgrep & ZAP report formats

Copy & paste into documents

Of twenty formats, one goes into a Word document as is (ZAP’s Traditional HTML), one is ready to send (ZAP’s PDF) and Semgrep’s text works with some formatting. The rest are too long for a document, or data for tools. All results below were tested in Microsoft Word.

Paste-ready · real tablesZAP

Traditional HTML

report.traditional.html · traditional-html template

How

  1. Open the .html file in Word (File → Open).
  2. Optional: delete the Insights table (scan statistics).
  3. Save as .docx.

Tested

  • Fits the A4 page width; 15 editable tables.
  • Every alert with description, URLs, evidence and fix.
  • 18 pages for 12 alerts; no HTTP traffic (the “plus” version has it: 35 pages).
Send as is · read-onlyZAP

PDF

report.pdf · traditional-pdf template

How

  1. Attach report.pdf to the e-mail or document as it is.
  2. Name it differently from the HTML report: ZAP deletes an HTML file with the same name.

Tested

  • 16 A4 pages, same content as the Traditional HTML.
  • Nothing to install or format for the reader.
  • Not editable: to change it, use the HTML version.
